## Назначение платформы

Платформа предназначена для получения, хранения, обработки и анализа корпоративных
данных.
В рамках проекта будут последовательно реализованы контейнеризация, автоматизация
обработки данных, аналитика и мониторинг.

## Docker

Первый сервис платформы контейнеризирован с помощью Docker.

Для сборки образа используется команда:

```bash
docker build -t corporate-data-app:2.0 ./app

```

## Kubernetes

Приложение может быть развернуто в локальном Kubernetes-кластере Docker Desktop.
Манифесты находятся в каталоге

```
kubernetes/
```

Основной Deployment:

```
corporate-data-deployment
```

PostgreSQL запускается отдельно через Docker Compose:

```
docker compose up -d db
```

Запуск Kubernetes-конфигурации:

```
kubectl apply -f kubernetes/deployment.yaml
```

Проверка:

```
kubectl get pods
```

### DuckDB

- Аналитический модуль корпоративной платформы.
- Позволяет выполнять SQL-запросы к данным CSV и объектам Data Lake, рассчитывать сводные показатели и формировать отчеты.


### NetworkX

- Графовый аналитический модуль корпоративной платформы.
- Используется для построения графовой модели организаций,
  городов и отраслей.
- Позволяет анализировать связи между объектами,
  рассчитывать центральность вершин,
  определять компоненты связности
  и находить кратчайшие пути.
- Поддерживает визуализацию структуры корпоративной сети
  с использованием Matplotlib.
