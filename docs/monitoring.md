
# Мониторинг Corporate Data Platform

## Назначение

Визуализация основных показателей корпоративной системы с помощью Grafana.

## Используемые компоненты

- Grafana
- PostgreSQL
- Docker Compose

## Источник данных

- PostgreSQL
- Таблица: companies

## Dashboard

Corporate Data Platform – Overview

## Основные показатели

1. Количество организаций.
2. Общая численность сотрудников.
3. Количество городов.
4. Количество отраслей.

## Визуализации

- Распределение организаций по городам.
- Численность сотрудников по отраслям.
- Крупнейшие организации.
- Средняя численность сотрудников по городам.

## Обновление

Интервал обновления: 30 секунд.

## Файл Dashboard

grafana/dashboards/corporate-overview.json

## Запуск

docker compose up -d db grafana

## Веб-интерфейс

http://localhost:3000

## Ограничения

- Реализован мониторинг бизнес-показателей.
- Технические метрики приложения пока не собираются.
