# Data Lake — Corporate Data Platform

## 1. Объектное хранилище

В проекте используется RustFS — S3-совместимое объектное хранилище.

- S3 API: `http://localhost:9000`
- Web Console: `http://localhost:9001`

## 2. Структура Data Lake

В хранилище используются две зоны:

- **RAW** — исходные данные без аналитической обработки.
- **PROCESSED** — обработанные данные после выполнения ETL-конвейера.

## 3. RAW

Bucket: `corporate-raw`

Object: `companies/companies.csv`

Источник данных: PostgreSQL, таблица `companies`.

RAW содержит исходные сведения о компаниях: идентификатор, название, отрасль, город и количество сотрудников.

## 4. PROCESSED

Bucket: `corporate-processed`

Object: `reports/companies_by_city.csv`

Отчёт формируется Apache Airflow в результате ETL-конвейера.

Содержит следующие показатели:

- город;
- количество компаний;
- общее количество сотрудников;
- среднее количество сотрудников на компанию.

## 5. ETL-конвейер

Последовательность обработки данных:

1. **Extract** — получение данных из PostgreSQL.
2. **Transform** — группировка компаний по городам и расчёт агрегированных показателей.
3. **Load** — формирование CSV-отчёта.
4. **Upload** — загрузка отчёта в RustFS, бакет `corporate-processed`.

## 6. Проверка обновления данных

Для проверки автоматического обновления в PostgreSQL добавлена новая компания `Cloud Data Lab`.

После повторного запуска DAG данные были извлечены из PostgreSQL, обработаны и сохранены в обновлённом CSV-отчёте в RustFS.
