# Аналитический отчет корпоративной системы

## Источник данных

RAW-данные организаций из Corporate Data Platform.

## Используемый инструмент

DuckDB.

## Рассчитанные показатели

- Количество организаций по городам.
- Общая численность сотрудников по городам.
- Средняя численность сотрудников.
- Максимальная численность сотрудников одной организации.

## Ограничения анализа

На основании имеющихся данных нельзя достоверно оценить:

- Прибыльность организаций.
- Производительность труда.
- Финансовую устойчивость организаций.
- Выручку и рентабельность компаний.

Для таких выводов необходимы дополнительные финансовые и экономические показатели.
