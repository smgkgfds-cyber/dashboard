
# Графовая модель Corporate Data Platform

## Назначение

Анализ связей между объектами корпоративной системы.

Графовая модель позволяет исследовать взаимосвязи
между организациями, городами и отраслями.

## Используемый инструмент

NetworkX.

Дополнительно используются DuckDB для чтения данных
и Matplotlib для визуализации графа.

## Источник данных

data/raw/companies.csv

## Типы вершин

- company – организация;
- city – город;
- industry – отрасль.

## Типы отношений

- located_in – расположение организации;
- operates_in – отраслевая принадлежность.

## Основные операции

- Создание графа.
- Поиск соседних вершин.
- Анализ общих связей.
- Расчет степеней вершин.
- Анализ центральности.
- Поиск компонент связности.
- Поиск кратчайших путей.
- Визуализация графа.
